# project-scaffold

Basic project setup using Vite, Node, and Git.

Minimal Vite + React (JSX) skeleton.

## Requirements

- Node.js 22+
- npm

## Setup

```bash
npm install
```

## Develop

```bash
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
